# Easy Editor

Простой графический редактор для базовых операций с изображениями. Приложение создано с использованием **PyQt5** и **Pillow (PIL)**.

## Описание

**Easy Editor** - это десктопное приложение с графическим интерфейсом, позволяющее просматривать и редактировать изображения в нескольких форматах. Оно идеально подходит для быстрой обработки фото без необходимости устанавливать тяжёлые редакторы.

## Функционал

Приложение позволяет:

* выбирать папку с изображениями;
* просматривать список доступных изображений (поддерживаются форматы: `.jpg`, `.jpeg`, `.bmp`, `.png`);
* выбирать изображение из списка для редактирования;
* применять к изображению следующие эффекты:
    * поворот влево (`90°` против часовой стрелки);
    * поворот вправо (`90°` по часовой стрелке);
    * отражение по горизонтали («зеркало»);
    * повышение резкости (контрастности);
    * преобразование в чёрно‑белое (градации серого);
* сбрасывать все применённые изменения, возвращаясь к оригиналу;
* сохранять отредактированное изображение в папку `Modified/` внутри выбранной директории.

## Интерфейс

Интерфейс разделён на две основные части:

1. **Левая панель**:
    * кнопка **«Папка»** - для выбора директории с изображениями;
    * список файлов — отображает отфильтрованные изображения из выбранной папки.
2. **Правая панель**:
    * область просмотра - показывает выбранное изображение;
    * ряд кнопок под областью просмотра для применения эффектов: **«Лево»**, **«Право»**, **«Зеркало»**, **«Резкость»**, **«Ч/Б»**, **«Сохранить»**, **«Сбросить фильтры»**.

## Технические детали

* **Язык программирования**: Python 3.x.
* **GUI‑фреймворк**: PyQt5.
* **Библиотека для работы с изображениями**: Pillow (PIL).
* **Стиль интерфейса**: кастомная цветовая схема с градиентами.
* **Сохранение результатов**: отредактированные изображения сохраняются в подпапку `Modified/` относительно исходной директории.

## Установка и запуск

1. Установите виртуальное окружение python 3.13.13
```bush
py - 3.13.13 -m venv myvenv
windows: myvenv\Scripts\activate
Linux: sourse myvenv/bin/activate
```
2. Клонируйте репозиторий
```bush
git clone https://github.com/RostiksOFF/Easy_Editor.git
```
3. Установите зависимости
+ PyQt5
+ pillow
